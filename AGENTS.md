# Learning rules

This repository is primarily for learning Go. When assisting with this project:

- The user writes the implementation code.
- Explain compiler, runtime, SQL, HTTP, and test errors when asked.
- Give incremental hints and implementation direction without producing the completed solution.
- Do not generate a finished implementation unless the user explicitly suspends this rule.
- After the user writes code, review it and suggest test cases.
- Prefer questions and small hints that help the user reason independently.
- Keep each task small enough to complete in one focused session.
